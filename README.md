# ADS-1SEM

# Sistema Web para Gestão de Academia

---

## Sobre o projeto

Estamos criando uma ideia de sistema para ajudar no dia a dia de uma academia. A proposta é deixar as informações mais organizadas e facilitar o trabalho de quem cuida dos alunos, dos planos e dos pagamentos.

## O que queremos facilitar?

- Cadastro e consulta dos alunos.
- Organização dos planos e das modalidades.
- Registro das matrículas.
- Controle das mensalidades e dos pagamentos.
- Consulta de quem está com pagamentos atrasados.
- Acesso ao sistema de acordo com a função de cada pessoa.

## Quem vai usar?

- **Administrador:** cuida das informações gerais da academia.
- **Recepcionista:** cadastra alunos, faz matrículas e registra pagamentos.
- **Professor e instrutor:** utilizam as informações necessárias para seu trabalho.
- **Colaborador:** acessa as partes liberadas pelo administrador.

## O que fizemos neste semestre?

- Conversamos sobre a ideia do sistema e o que ele precisa oferecer.
- Organizamos as principais funções.
- Definimos quem poderá utilizar o sistema.
- Montamos a lista de requisitos e os casos de uso.
- Criamos exemplos de algoritmos e fluxogramas.
- Preparamos os documentos e organizamos os arquivos do projeto.

Mais adiante, o sistema poderá ganhar outras funções, como uma área para os alunos, acompanhamento de treinos, avaliações físicas e opções de pagamento pela internet.
